
# Helsebot – LEGO-basert helseassistentrobot

### IDATG1004 – Teambasert samhandling | NTNU Gjøvik

## Prosjektbeskrivelse

Helsebot er et tverrfaglig gruppeprosjekt gjennomført som en del av dataingeniørstudiet ved NTNU Gjøvik.

Prosjektets formål var å undersøke hvordan robotteknologi kan brukes til å utvikle en teknisk løsning som kan bidra til å støtte personer i situasjoner der rask tilgang til helsehjelp er viktig.

Gruppen arbeidet med å utvikle en LEGO-basert robotprototype som demonstrerer sentrale prinsipper innen robotikk, motorstyring og teknologisk problemløsning.

## Problemstilling og mål

Prosjektet tok utgangspunkt i utfordringer knyttet til tilgjengelighet og responstid i helsetjenesten, særlig i områder med store geografiske avstander.

Målet var å utforske en robotbasert løsning som på sikt kunne bidra til kommunikasjon, varsling og støtte i nødsituasjoner.

Prosjektarbeidet omfattet planlegging, utvikling, testing og dokumentasjon av en fysisk prototype.

## Teknologier og verktøy

- LEGO-baserte konstruksjonskomponenter
- Robotmotorer og mekaniske komponenter
- Sensorer og elektroniske komponenter
- Git og GitHub for versjonskontroll
- Overleaf og LaTeX for teknisk rapportskriving
- Microsoft Teams for kommunikasjon og samarbeid

## Utviklingsprosess

### Planlegging og organisering

Gruppen startet med å analysere problemstillingen, definere prosjektmål og fordele arbeidsoppgaver.

Det ble utarbeidet en prosjektplan og arbeidet med fremdriftsplanlegging, dokumentasjon og koordinering av gruppens aktiviteter.

### Utvikling av robotprototype

Prosjektet omfattet konstruksjon og videreutvikling av en fysisk robotprototype.

Under utviklingen undersøkte gruppen hvordan mekaniske komponenter, motorer og sensorer kunne kombineres i en fungerende robotkonstruksjon.

### Testing og videreutvikling

Robotprototypen ble videreutviklet gjennom praktiske undersøkelser og vurderinger av tekniske løsninger.

Arbeidet ga erfaring med utfordringer knyttet til robotkonstruksjon, motorstyring, mekanisk stabilitet og samspillet mellom ulike komponenter.

## Samarbeid og prosjektgjennomføring

Helsebot ble utviklet gjennom samarbeid mellom fire gruppemedlemmer.

Prosjektarbeidet omfattet blant annet:

- Planlegging og fordeling av arbeidsoppgaver

- Dokumentasjon av prosjektarbeidet
